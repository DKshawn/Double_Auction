# Demo Model

デモ一覧と各画面は黄色系で表示し、ヘッダーの「市場実験室」の横に「DEMOモード」のテキストラベルを表示します。正式画面と同じ青紫色の「DEMOモードを終了」で学生入口へ戻れます。

[日本語](../ja/demo.md) · [中文](../zh-CN/demo.md) · [English](../en/demo.md)

教員ログイン後、**Demo Model** から `/demo/select` を開いて実験を選びます。デモや画面サイズ別プレビューのURLを直接開いた場合は、教員ログイン後に元の画面に戻ります。学生のルームへの入室情報は正式実験の参加に使います。

デモモードのヘッダーの「市場実験室」から実験選択へ戻れます。3つのデモの設定画面では、「戻る」で一覧へ、「教員用ページへ」で教員ページに戻れます。EMHのデモルームでは「戻る」を常に表示し、「教員用ページへ」は教員画面に表示します。

## Double Auction

`/demo` を直接開くか、デモ一覧で Double Auction を選びます。正式な教員ページと同じ実験設定フォームから開始します。初期値は1市場・16人ですが、制度・各制度の期数・市場数・人数・時間を設定でき、正式なルーム作成と共通のルールで検証します。

1. 「デモルームを作成」を押すと、あなた1人と仮想参加者が入室した教員画面を開きます。作成前に設定する場合は「作成前に詳細を設定」を開きます。開始前は「実験設定を変更」で制度・期数・時間・価値・費用を変更できます。
2. 「入室を締め切って割り当て」または締切タイマーで実際の人数を市場と買い手・売り手に分け、「実験を開始」で5秒のカウントダウン後に取引を始めます。「学生画面を見る」で待機から取引画面への切替も確認できます。
3. 選択した制度を設定した期数だけ実施します。CDAは注文板から取引、Callは公開注文を期限に一括清算、Postedは売り手の提示公開後に全買い手が提示価格で直接購入します。
4. 「教員画面を見る」で全市場の結果と、選択した市場の買い手・売り手双方の注文・条件・利益を確認します。教員画面の表示対象は両側に固定され、役割は変更できません。
5. 「一時停止」は全市場の時計と仮想参加者を停止。「30秒進める」は各市場の清算・購入を実行しながら時間を進めます。各制度の最終期は8秒間の結果確認を行ってから進み、設定した合計期数で終了します。教員画面に切り替えても、あなたの代わりに注文・購入することはありません。
6. 「実験設定に戻る」で直前の制度・期数・人数・時間を保持した設定フォームに戻り、変更して新しいデモを作成できます。

正式実験と同じ成立・清算・在庫・利益計算を使いますが、初期の価値・費用はデモ専用です。人数を変更すると正式実験と同じ方法で条件を抽出・複製します。CDAでは各期の開始から3秒間を考える時間とし、その後は買い手・売り手の両方が2秒ごとに注文を出します。最初は自分の条件に対して余裕のある希望価格を提示し、時間とともに希望利益幅を小さくします。CallとPostedでは固定マージンの注文を出します。人間の学習・収束を再現するモデルではありません。状態はブラウザーのメモリ内だけに存在し、API・Cookie・Neonへの書き込みはありません。再読み込みは最初の設定画面に戻り、役割の変更・「やり直す」は設定した構成で進行をリセットします。背景タブでは進行を止めます。

`/demo/preview` またはデモの「デモについて」内のリンクから、ノートPCサイズの操作可能なプレビューを開けます。1366×768（100%）、1920×1080（125%・150%・100%）、MacBook Pro 14インチ（1512×982・Retina 2×）とiPad Pro 11・13インチを含む7設定を切り替え、ブラウザー・OSのバー相当の高さ120 CSS pxを差し引くか選べます。MacBook Proは3024×1964物理画素を2×表示した場合の論理サイズでプレビューし、余白を差し引いた表示領域は1512×862 CSS pxです。実際の余白はOS・ブラウザー設定で異なります。ひとつの`/demo`を固定サイズのiframeで表示するため、サイズ切替でデモは再読み込みされず、取引・教員表示も保持されます。「全体に合わせる」は外側の表示のみを縮小し、「原寸」は100%で表示します。デモの表示領域とプレビュー倍率を併記します。埋め込みは同一オリジンの`/demo`と`/emh/demo`に許可し、教員・正式実験のページは引き続き埋め込みを禁止します。

プレビューも教員の設定フォームから開始します。作成後は開始・一時停止・リセット・役割選択・設定に戻るなどのデモ操作を枠の外に表示し、実験画面の高さを消費しません。同一オリジンのReact Portalで同じデモセッションを操作します。通常の`/demo`は画面内に操作パネルを表示します。

## EMH

価格・配当・売買収支・得点は画面上で円と表示します。

開始後は取引画面の「あなたの条件」の真上に5秒間のカウントダウンを表示し、条件を同じ位置で矢印と枠で強調します。条件が画面外にある場合は見える位置に移動します。一時停止中はカウントダウンも止まります。

[EMH の Demo Model](https://exp-all-in-one.vercel.app/emh/demo) では実験1または実験2を選びます。実験1は正式実験と同じ設定フォーム・入力範囲・既定値を使います。初期証券数、目標人数、タイプ比率、A/B各期の時間を設定し、「デモルームを作成」を押します。目標人数3〜12人の1市場を作り、あなた以外は仮想参加者です（既定8人）。

受付中の「設定を保存」、分け方の確認とロック、開始前の明示的な解除は正式実験と同じ手順です。確定したタイプは開始時に再抽選しません。ラウンド数・1取引と休憩の時間は設定でき（既定は6回・30秒・60秒）、証券数・時間・配当・効率は共通エンジンで計算します。練習配当（円）はタイプ1〜3でA/B各120/40、100/60、150/30であり、正式実験の非公開配当は使いません。

実験2のデモは1市場（3〜999人）で、既定はあなたと仮想参加者11人です。初期証券数、目標人数、タイプ比率、連続不成立で終了する回数、内部情報の開始ラウンドと各タイプの人数、状態の確率・タイプ別配当・実現状態を変更できます。市場数はデモでは1市場です。既定の練習用配当（円）は80/110/170・60/180/100・140/120/90、実現状態は3/3/3/3/2/2で、正式実験とは異なります。仮想参加者は自分の情報に基づいて取引します。

実験1・2の条件パネルは正式画面と共通で、買い・売りそれぞれで指値・成行ボタンを横に並べます。教員・学生ともに注文板の「一覧」には価格と数量が並びます。学生は「一覧」と「棒グラフ」の両方で自分の指値を確認できます。他の参加者の注文や1取引の時間切れの後も未成立の指値は期末まで残り、本人が変更・取消できます。実験2は状態別配当・確率・期待配当・Clueをまとめ、取引記録と個人のラウンド記録を同時に表示します。教員画面の「実験条件」ボタンで条件を開閉できます。

EMHデモの操作パネルでは、教員・学生画面の切替、一時停止、30秒進める、次の期へ進む、やり直す、設定の見直しができます。時間を進めると仮想参加者の取引と期限も順に処理されます。カウントダウン中や一時停止中は早送りできません。「やり直す」は設定を保って割り当てと進行をリセットします。画面サイズ別プレビューでは操作パネルを枠外に表示します。

EMHの画面サイズ別プレビューは `/emh/demo/preview` またはデモ設定画面の「画面サイズ別プレビュー」から開けます。PC・iPad・スマートフォンのサイズを切り替えられ、実験画面と進行状況は切り替え後も保持されます。ブラウザー・OS用の高さ120pxの差し引きや、全体表示・原寸も選択できます。

「設定を見直す」は現在の保存済み設定をフォームに戻し、次の作成で進行をリセットします。再読込は既定の設定画面へ戻ります。デモの状態はブラウザー内だけで保持し、正式ルームやNeonへ書き込みません。[正式実験の条件](emh.md)も参照してください。

## Judgement under Uncertainty

課題カード、選択数・一覧、ランダム化設定は正式実験と共通です。右側の操作欄で「デモを開始」を押します。狭い画面では操作欄がカードの上に移ります。設定画面は日中英を切り替えられ、プレビューを閉じても選択が残ります。プレビューは教員が選んだ言語で開き、学生画面内で切り替えることもできます。

[Judgement の Demo Model](https://exp-all-in-one.vercel.app/judgment/demo) では、課題を選んで学生画面を確認できます。丸い **i** ボタンで課題の詳細を開けます。回答は保存せず、制限時間を停止したプレビューです。正式な計時や回答記録の確認には、隔離したローカル環境の検証手順を使ってください。

EMHでは全員が提示でき、相手の価格を受ける操作と跨ぐ提示は1単位が即時成立します。学生は匿名の取引記録と注文板で自分の未成立の指値を確認でき、実験1の得点にはB期末まで「暫定」と表示します。
