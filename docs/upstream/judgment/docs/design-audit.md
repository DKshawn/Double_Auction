## 教师编排与记录

学生以7位学生证号登录后等待。教师选择实验块，按开始后，每位学生取得一次持久化分配。实验顺序随机化按学生独立进行；关闭时采用章节顺序。选择按钮位置随机化独立设置，原研究的组间条件、数字量尺、乘法方向操纵和任务阶段不受该按钮设置影响。

两种随机设置、教师所选实验、学生实际顺序、选项值顺序、条件与种子均保存在SQLite，并进入导出。刷新不会重新分组。全部14项共86个作答／准备页面，包含24次袋—罐判断和完整30项风险任务。取消通用接触经历问题。一个教学实施结束后，相同学生证号可参加下一次独立实施。

所有任务均有翻译、屏幕化及连续呈现的改变；未进行三语回译或跨语言测量等价性验证，不能据功能测试声称心理效应复现。服务器仍为本机预览，跨电脑课堂接入和教师身份认证尚未实现。
