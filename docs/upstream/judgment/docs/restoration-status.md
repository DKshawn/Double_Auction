## 数据与方法

- 新程序均有独立版本。历史回答、旧刺激、原语言快照保留，不用新版内容重写。
- 谈话只在**同一教学实施**、双方互填对方学号时配对；未配对原始回答照常保留。配对量是自己的估计减对方对自己的估计，绝不是客观准确率。
- 赔率保存两项原值，允许小数与一边为0，禁止双0。导出用明确的`Infinity`／`-Infinity`字符串保留无穷赔率或对数赔率。
- 风险评分先给全部30项排名，允许并列；最低项固定10，其余无100上限。原始选择和倍数保留；可接受更高风险时调整因子为1/k，需要更安全时为k。九量尺有序端点不受选项随机开关影响。
- 教师实验顺序随机不会打断任务内部阶段。翻译、屏幕化、连续实施和课堂样本仍可能影响结果；软件检查不等于已验证心理效应或三语等价性。
