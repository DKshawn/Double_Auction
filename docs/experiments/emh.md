## 統合版での実施

教員は `/teacher` のキー認証後に EMH を選んでルームを作り、学生は共通の `/` から入室します。教員ページの **Demo Model** から、正式実験と共通の設定・確定手順で練習できます。デモは目標人数の1市場と仮想参加者を作り、全6ラウンド・共通の証券数、比率、時間を適用します。配当だけは公開練習値120/40・100/60・150/30を使います。

参加者全員を設定した目標人数に近い市場へ自動分けします（既定9人）。1市場3〜12人、市場間の人数差は最大1人。各タイプを最低1人確保し、希望比率に対する不足が最大のタイプへ残りを配分します。同点は全市場の偏りで調整します。既定比率1:1:1では従来どおり均等になります。総供給は実人数×設定した初期証券数、初期配分の配当は実際のタイプ構成から計算します。

確定時に条件・市場・個人のタイプを保存してロックします。開始前に明示して割り当てを解除した場合のみ再設定できます。旧ルームは初期2単位などの従来値を維持し、確定済みの得点は再計算しません。

市場ごとに取引と時計を独立して進め、教員は全市場の開始・一時停止・再開と選択市場の期終了を操作できます。各ラウンドの持分・売買収支・配当はリセットし、確定得点を累積します。

理論価格は A期の私的情報均衡340、完全予見均衡367、B期110（p.15–18）。他のタイプの配当・成績・理論価格は、終了後に教員が解説を公開するまで学生に送りません。

## 記録

平均価格を完全予見均衡価格で割った `priceRatio`、総配当の比率 `allocationEfficiency`、初期配分からの改善比率 `gainEfficiency` を区別します。p.21 の価格比の日本語注記と引用表脚注の効率指標を混同しないためです。

教員は市場別または全市場の CSV と条件・割り当ての JSON を出力できます。JSONは希望比率・実人数・初期証券数・時間・確定時刻を保存し、結果CSVにも実人数・初期証券数・総供給・各期秒数を含めます。学生の CSV は本人の履歴のみです。

実装は `src/experiments/emh`、設定は `server/default-config.ts`、検証は `tests/emh-engine.test.ts`、`tests/emh-platform.test.ts` と `scripts/verify-emh-http.ts` にあります。[旧版の原文・ハッシュ記録](../upstream/emh/NOTICE.md) も保存しています。
