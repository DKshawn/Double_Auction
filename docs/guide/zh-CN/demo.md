# Demo Model

[日本語](../ja/demo.md) · [中文](../zh-CN/demo.md) · [English](../en/demo.md)

登录后可从各实验教师页面右上角的 **Demo Model** 进入。直接打开下方公开演示地址无需登录，也不会创建正式房间。

三个 Demo 的设置页均可通过页眉的「教員用ページへ」返回教师页面。EMH 进入演示房间后也保留此按钮。

## Double Auction

直接打开 [`/demo`](https://exp-all-in-one.vercel.app/demo)，或使用教师页面的 **Demo Model**。无需登录，起始页面与正式实验共用设置表单。默认1个市场、16人，可设置制度、各制度期数、市场数、人数和时间，采用与正式创建房间相同的校验规则。

1. 点击「デモルームを作成」，打开包含你和虚拟参加者的教师画面。创建前可以打开「作成前に詳細を設定」；开始前可以通过「実験設定を変更」调整制度、期数、时间、价值与成本。
2. 手动点击「入室を締め切って割り当て」或等待截止计时器，将实际参加者分到市场及买卖角色。点击「実験を開始」后倒数5秒进入交易。「学生画面を見る」可以查看从等待到交易的切换。
3. 按设置的期数依次运行制度。CDA 使用订单簿成交；Call 在截止时对公开订单集中清算；Posted 在卖方报价公开后允许所有买方以报价直接购买。
4. 「教員画面を見る」显示全部市场结果，以及所选市场双方的订单、条件和利润。教师视图固定同时显示买卖双方，不能在此切换角色。
5. 「一時停止」暂停全部市场时钟和虚拟参加者。「30秒進める」在推进时间的同时处理清算和购买。每个制度的最后一期会展示结果8秒，再进入下一制度；达到设置的总期数后结束。切到教师视图不会让系统替你下单或购买。
6. 「実験設定に戻る」返回设置表单，保留刚才的制度、期数、人数和时间，修改后可创建新的演示。

演示复用正式实验的成交、清算、库存和利润计算，但初始价值与成本是演示专用的。改变人数时，按正式实验同样的方法抽取或复制条件。CDA 每期开始后的3秒为思考时间，随后虚拟买卖双方每2秒下单：起初保留较大利润空间，之后逐渐缩小。Call 和 Posted 使用固定利润幅度；这些行为不模拟人类学习或价格收敛。

演示状态只保存在浏览器内存中，不写入 API、Cookie 或 Neon。刷新会返回初始设置页；角色切换和「やり直す」按当前构成重置进度。标签页进入后台时暂停。

### 屏幕尺寸预览

打开 [`/demo/preview`](https://exp-all-in-one.vercel.app/demo/preview)，或使用演示中「デモについて」内的链接，可在可操作的笔记本尺寸预览中检查布局。七个预设包括1366×768（100%）、1920×1080（125%、150%、100%）、14英寸 MacBook Pro（1512×982、Retina 2×）以及11和13英寸 iPad Pro。可选择扣除120 CSS px，模拟浏览器与系统栏。

MacBook Pro 预设将3024×1964物理像素按2×换算为逻辑尺寸，扣除预留高度后为1512×862 CSS px；实际系统和浏览器占用的高度可能不同。预览用同一个固定尺寸 iframe 显示 `/demo`，切换尺寸不会重新加载演示，也不会丢失交易或教师视图。「全体に合わせる」只缩放外部显示，「原寸」使用100%，页面同时列出内部显示区域及预览倍率。仅允许同源 `/demo` 和 `/emh/demo` 被嵌入；教师与正式实验页面仍禁止嵌入。

预览同样从教师设置表单开始。创建后，开始、暂停、重置、角色选择和返回设置等控制放在框外，不占用实验画面高度，并通过同源 React Portal 操作同一演示会话。普通 `/demo` 的操作面板显示在页面内。

## EMH

界面上的价格、分红、买卖收支与得分均以「円」标注。

[EMH Demo Model](https://exp-all-in-one.vercel.app/emh/demo) 可选择实验1或实验2。实验1与正式实验共用设置表单、输入范围和默认值。设置初始证券数、目标人数、类型比例和A/B各期时间后，点击「デモルームを作成」。演示建立一个3至12人的市场，除你之外都是虚拟参加者，默认8名虚拟参加者。

开放加入时的「設定を保存」、分组确认锁定和开始前明确解除，都采用正式实验相同的操作步骤。开始时不会重新抽取已确认的类型。固定6轮、每次交易最多30秒、休息60秒，证券数、计时、分红与效率使用共用引擎。练习分红（円）为类型1至3的A/B各120/40、100/60、150/30，不使用正式实验的非公开分红。

实验2不可调节条件，使用你和11名虚拟参加者组成的一个市场，进行6轮练习。每种类型4人，第1、2轮无人知情，第3至6轮各类型2人看到 Clue 卡；每轮最长5分钟，每人初始持有2单位。练习分红（円）为80/110/170、60/180/100、140/120/90，实际状态依次为3/3/3/3/2/2。虚拟参加者根据各自的信息交易。

实验2的学生画面将各状态的分红与概率并列，买价和卖价可分别直接输入，同时显示市场成交价格与个人轮次记录。 实验2进行中，可在教师画面通过「実験条件」按钮展开或收起固定条件。

EMH 的屏幕尺寸预览可从 `/emh/demo/preview` 或演示设置页的「画面サイズ別プレビュー」打开。可切换电脑、iPad 和手机尺寸；框内的演示操作与进度在切换时保持不变。还可选择扣除120px模拟浏览器与系统栏，并在适应窗口和原寸之间切换。

「設定を見直す」把当前已保存设置带回表单，再次创建后重置进度；刷新则回到默认设置页。演示状态只保存在浏览器内，不创建正式房间，也不写入Neon。另见[正式实验条件](emh.md)。

## Judgement under Uncertainty

任务卡片、已选数量和列表、随机化设置与正式实验共用。在右侧操作区点击「デモを開始」；窄屏时操作区移到卡片上方。设置页支持日中英切换，关闭预览后保留本次选择。预览以教师所选语言打开，也可在学生画面内继续切换。

[Judgement Demo Model](https://exp-all-in-one.vercel.app/judgment/demo) 在选择任务后显示学生画面。点击圆圈 **i** 查看任务详情。预览不保存回答，计时限制暂停。需要验证正式计时和回答记录时，请使用隔离本地环境中的验证流程。
